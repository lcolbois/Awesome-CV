\begin{cvletter}
I'm a machine learning engineer with a PhD from UNIL/Idiap, transitioning from research into applied ML engineering after five years building and evaluating ML systems at the Idiap Research Institute.

The data-centric core of this role is where I'm strongest: I build end-to-end ML pipelines in Python, from data collection and preprocessing through model evaluation and reporting, with solid MLOps practices (Hydra, MLflow, Snakemake) to keep things reproducible. My PhD work involved large-scale systematic evaluation of deep learning classification models on image data; my postdoc extended this to designing custom metrics and automated analysis pipelines for vision-language models.

I haven't worked directly with sensor or radar data, but I'm not starting from zero. My MSc thesis applied deep learning to raw audio signal processing, learning signal representations directly from data for speech enhancement, and at Logitech I deployed an audio classification model to embedded hardware under real-time latency and memory constraints. Moving into this domain is a genuine step, but one I'd take with a signal-processing foundation already in place.

During the Idiap Create Challenge 2025, a 9-day startup hackathon in a team of three, I built the working prototype end-to-end and co-presented the pitch, winning first place. This kind of end-to-end ownership is a big part of what draws me to applied ML engineering. I'm available immediately and a native French speaker fluent in English.


\end{cvletter}
